## Phases

### Phase 1 — Foundation ✅ Done (v8.15.0)

- `internal/vision/service.go` — `Describer` interface + `HTTPVisioner`
  - Backend: `ollama` (native `/api/generate` + `images` base64 array)
  - Backend: `openai` / `openai_compat` (`/v1/chat/completions` with `image_url` content part)
- `VisionConfig` in config (`enabled`, `backend`, `endpoint`, `api_key`, `model`, `default_prompt`, `max_image_bytes`)
- `POST /api/vision/describe` — multipart `image` field + optional `prompt`
- `vision.*` keys in `GET /api/config` + `PUT /api/config`

### Phase 2 — Comms router ✅ Done (v8.15.0)

- `Attachment.IsImage()` in `internal/messaging/backend.go`
- `Visioner` interface + `SetVisioner()` in router
- Image attachment block in `processMessage`: read file → `Describe()` → prepend `[image: <desc>]` to `msg.Text`
- Mirrors audio transcription block exactly (same error/empty/break-on-first pattern)
- Wired into all routers (Signal, Telegram, test router) + HTTP server in `main.go`

### Phase 3 — MCP tool + session injection (pending)

- `vision_describe` MCP tool: `vision_describe(image_path, question, backend, model)`
- `image_paths: [...]` field on `start_session` and `session_send` REST + MCP surfaces
- Sessions with text-only backends receive descriptions; vision-capable backends receive raw image

### Phase 4 — Skills + PRD + memory + council (pending)

- Skills `accepts_images: true` manifest flag; `{{image_description}}` injection
- PRD decompose with image context (architecture diagrams, mockups)
- `remember [image]` via comms — description stored in episodic memory
- Council `image_path` parameter — description injected into every persona prompt
- Alert `chart_path` + `alerts.vision_summary` — vision summary appended to alert message
- BL366 verifier: `quality_gates.screenshot_path_glob` — screenshots described and passed to verifier

## Config reference

```yaml
vision:
  enabled: false
  backend: ollama          # "ollama" | "openai" | "openai_compat"
  endpoint: http://localhost:11434
  api_key: ""              # optional; required for upstream OpenAI
  model: llava             # must be vision-capable; no auto-detection
  default_prompt: ""       # defaults to "Describe this image concisely."
  max_image_bytes: 0       # 0 = 10 MB default
```

## Supported models

| Backend | Models |
|---|---|
| ollama | llava, llava-phi3, llava-llama3, bakllava, moondream, minicpm-v |
| openai | gpt-4o, gpt-4-vision-preview |
| openai_compat | any model served via an OpenAI-compatible endpoint |
