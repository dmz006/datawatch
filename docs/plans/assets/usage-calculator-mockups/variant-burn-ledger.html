Example queue, not real data

Queued Automata: 6, estimated 2.4 points plus decomposes.

Six full Automata at 0.4 is 2.4 points. If each has one decompose at 0.15, the decomposes add 0.9 points, so the example queue comes to 3.3 points.

Run flat out uses 20 points of remaining work from the model input, the design's worked example. The example queue prices out at 3.3, not 20, so the two do not agree yet. The operator decides which figure to enter.
