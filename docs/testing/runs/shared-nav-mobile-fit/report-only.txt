   /home/user/workspace/datawatch, outside the worktree. The probe imports node built-ins
   only, so the install is not needed. The symlink is unchanged after the run.
3. TEST_BINARY points at sandbox/run-daemon.sh, which execs the same binary and appends
   its output to sandbox/daemon.log. e2e-pwa.sh deletes its own run dir, including
   daemon.log, after a passing run, so without this the daemon log would be lost.
4. The probe's Chrome profile and temp dirs lived under bin/sandbox (gitignored) and were
