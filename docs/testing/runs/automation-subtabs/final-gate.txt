## Judgment calls

1. Triage card placement: the Needs-attention/triage card
   (`#automationTriageCard`) stays on the Chains sub-tab, rendered above the
   list (app.js, `_AUTOMATION_SUBTABS` entry for `chains`, with the
   decision comment in source). Rationale: it enumerates the failed/blocked
   Automata that need an operator; burying it on the non-default Overview
   sub-tab would hide operator-waiting items and regress the pre-split
   behavior. The capacity/usage/progress/lane-fill cards went to Overview.
2. English placeholders in the non-English locale bundles:
   `automation_subtab_overview` ("Overview") and `automation_subtab_chains`
   ("Chains") ship as English strings in de.json, es.json, fr.json and ja.json
   for now. They are covered by an explicit PENDING_TRANSLATION allow-list in
   internal/server/web/app-automation-locales.test.js (which still requires
   the same key set, placeholder parity, ≥80% translation of the other
   Automation values, and the absence of internal vocabulary or tracker IDs
   in every bundle), so the gap is tracked by a failing-by-construction test
   the moment either key is dropped from the bundles.
3. node --test invocation: the directory-argument form is not usable on node
   v24.15.0 in this environment (MODULE_NOT_FOUND, counted above in step 2);
   the glob `internal/server/web/*.test.js` was used and provably spans the
   same 123 test files, so the suite result is unchanged in scope.
4. Guard stories from step 7 are cited, not re-run, because app.js and
   style.css predate that 08:38 run's record.
