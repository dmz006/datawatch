# Bounded load-step rule

Record the bounded-load-step posture for '{{feature}}': Any CPU-load or stress step a task asks for — a busy loop, a stress test, a load or soak test, or any other command that pins the CPU — must be bounded before it runs: run it niced (nice -n 19) so it yields to the system's other work; use at most a quarter of the cores (cap the worker count at nproc/4, minimum one); give it its own hard timeout (a bounded "timeout <duration> ..." wrapper) so it always dies on its own; clean up its children with a trap on EXIT INT TERM so no orphaned load survives; and it must never outlive its owning task — when the task ends, the load ends with it. Automaton plans tasks to leave the host as it found it, so an unbounded load step is a defect in the plan. This is a note, not a change: it writes no files and touches nothing else (no files).
